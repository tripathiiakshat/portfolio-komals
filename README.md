## How to Run

### Option 1: Double-click
Double-click `start.bat` in this folder. It will launch the server and automatically open the portfolio in your browser at `http://localhost:3000`.

### Option 2: Command Line
```bash
npm start
# Or directly:
node server.js
```
Then visit `http://localhost:3000` in any web browser.

### Option 3: Direct File
You can also open [index.html](file:///c:/Users/Dell/Desktop/Portfolio/index.html) directly in any modern browser.
